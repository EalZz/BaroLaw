# BaroLaw RAG 검색 엔진 성능 평가 리포트 (Phase 4)

## 1. 개요 (Overview)
본 평가는 BaroLaw 법률 AI 챗봇의 **검색(Retrieval) 단계** 성능을 정밀 측정하고, 현재 시스템의 임계값(\THRESHOLD = 0.30\) 설정이 실전 환경에서 유효한지 검증하기 위해 수행되었습니다.

---

## 2. 실험 환경 (Environment)
- **대상 데이터**: 법령 및 QA 데이터 약 5,340건
- **평가 데이터**: 
  - **정상 셋**: DB에서 추출된 정제된 질문 (125건)
  - **가혹 셋 (Hard Set)**: 실제 상담 게시판 스타일로 변조된 구어체 질문 (30건 -> 100건 확장 진행 중)
- **비교 알고리즘**:
  1. **BM25 (Lexical)**: 전통적인 키워드 매칭 방식
  2. **Vector (Semantic)**: \ko-sroberta\ 임베딩 기반 의미 검색 (현재 시스템)
  3. **Hybrid (RRF)**: 위 두 방식의 가중치 혼합 방식
